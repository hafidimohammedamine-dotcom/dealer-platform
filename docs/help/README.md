# Help center

**Status: no help pages are written yet.** This page is the index. Each task will get its own page here, and each page
will be in plain English for the dealer and their staff, not for engineers.

## How each page is written

- One page per task. The title is the task, for example "Desk a deal".
- Short sentences. Numbered steps.
- Say what you will see on the screen, and what to do if it does not look like that.
- No code, no environment variable names and no internal links.
- Fake examples only: a made-up customer name, a `555` phone number, a made-up stock number.
