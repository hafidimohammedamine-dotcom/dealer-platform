# 2026-10-12 - Playwright e2e harness skeleton (#24)

- **Workspace:** new `tests/e2e` (`@dealer/e2e`) with Playwright 1.64.0 (exact pin, Apache-2.0). It has the same
  `typecheck`, `test` and `build` scripts as the other workspaces, plus `e2e`. The root `yarn e2e` runs it.
- **Smoke test:** a spec that uses Playwright's request client against a small local server (`src/server.ts`, bound to
  `127.0.0.1` on a random port). It needs no browser and no database. The server has unit tests with full coverage.
- **Browsers:** not downloaded at install (lifecycle scripts are off). Install by hand when needed:
  `yarn workspace @dealer/e2e playwright install chromium`.
- **Base URL:** `E2E_BASE_URL` is an optional, non-secret base URL, documented in `docs/dev/env-vars.md`. It is not in
  `.env.example`.
- **Git-ignored:** `test-results/` and `playwright-report/`.
- **Not done yet:** shared fake data in `fixtures/` (issue #7, the folder has only a README), the cross-dealer leak tests
  (issue #5), lint and `infra/checks` coverage of `tests/*` (issue #66) and a CI step for `yarn e2e` (issue #62).
- **Docs:** `docs/dev/setup.md` (the `yarn e2e` row and notes), `docs/architecture.md` and `docs/dev/env-vars.md`.
