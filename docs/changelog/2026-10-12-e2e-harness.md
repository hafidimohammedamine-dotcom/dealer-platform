# 2026-10-12 - E2E harness (#24)

- **Workspace:** `tests/e2e` (`@dealer/e2e`) with Playwright 1.64.0, pinned exactly (Apache-2.0). Browsers are not
  downloaded at install, because install scripts stay off.
- **Command:** `yarn e2e` runs `playwright test --config playwright.config.ts` in `@dealer/e2e`. It is not part of
  `yarn test`, and CI does not run it yet. Adding the step to `ci.yml` is founder-only and is tracked in issue #62.
- **Smoke spec:** one spec, `tests/e2e/specs/smoke.spec.ts`. It uses Playwright's request client against a local health
  server (`tests/e2e/src/server.ts`, bound to 127.0.0.1 on a random port), so it needs no browser.
- **Browser specs:** none yet. When one is added, a browser must be installed once per machine, by hand:
  `yarn workspace @dealer/e2e playwright install chromium`.
- **`E2E_BASE_URL`:** a non-secret base URL of the app under test, read by `playwright.config.ts`. It has no default.
  It is not in `.env.example`. See [Environment variables](../dev/env-vars.md).
- **Output:** `tests/e2e/test-results/` and `playwright-report/` are git-ignored by `tests/e2e/.gitignore`. `dist/` is
  git-ignored by the root `.gitignore`.
- **Fixtures:** `fixtures/` holds only a README. Shared fake data (leads, texts, credit apps, lender callbacks, two fake
  dealers) comes with issue #7. Leak tests (one dealer cannot see another's data) come with issue #5.
- **Not yet:** `tests/*` is not in the ESLint ignore list or the `infra/checks` workspace list (issue #66). Until then,
  ESLint and Prettier do not skip its output folders. See [Developer setup](../dev/setup.md).
