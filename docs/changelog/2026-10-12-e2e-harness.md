# 2026-10-12 - Playwright e2e harness skeleton (#24)

- **Workspace:** new `tests/e2e` (`@dealer/e2e`) with Playwright 1.64.0 (exact pin, Apache-2.0). It has the same
  `typecheck`, `test` and `build` scripts as the other workspaces, plus `e2e`. The root `yarn e2e` runs it.
- **Smoke test:** a spec that uses Playwright's request client against a small local server (`src/server.ts`, bound to
  `127.0.0.1` on a random port). It needs no browser and no database. The server has unit tests with full coverage.
- **Browsers:** a one-time manual install, only if a spec needs one:
  `yarn workspace @dealer/e2e playwright install chromium`. It downloads binaries at run time, so run it only on a
  developer machine or in a CI job with no secrets. `PLAYWRIGHT_DOWNLOAD_HOST` must not be set. See issue #62.
- **Base URL:** `E2E_BASE_URL` is an optional, non-secret base URL, documented in `docs/dev/env-vars.md`. It is not in
  `.env.example`.
- **Git-ignored:** `test-results/` and `playwright-report/`.
- **Fixtures:** `fixtures/dealers.json` holds two fake dealers (staff, inventory, customers; fake SSNs in the
  900-xx-xxxx range). Checked by `src/fixtures.test.ts`. The lead, text and lender fixtures come in issue #7.
- **Tests:** `src/config.test.ts` covers `E2E_BASE_URL` set and unset; `specs/base-url.spec.ts` covers a relative path
  with a base URL and the failure when there is none.
- **Depends on #66:** `eslint.config.mjs`, the `infra/checks` `workspaceFolders` list and `.prettierignore` do not yet
  cover `tests/*` (`tests/e2e/dist`, `coverage`, `test-results`, `playwright-report`). Issue #66 (devops) fixes this and
  must merge before this PR.
- **Not done yet:** the cross-dealer leak tests (issue #5) and a CI step for `yarn e2e` (issue #62).
- **Docs:** `docs/dev/setup.md` (the `yarn e2e` row and notes), `docs/architecture.md` and `docs/dev/env-vars.md`.
