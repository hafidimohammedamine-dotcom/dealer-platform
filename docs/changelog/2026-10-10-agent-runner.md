# 2026-10-10 - Agent jobs run on the founders' PCs (#33)

- **Every job with a Claude step runs on the agents' self-hosted runners** (`runs-on: [self-hosted, agents]`: manager,
  review team, daily report, weekly audit, founder mentions, the lock-with-Claude tests), so the agents work 24/7 at no
  GitHub cost. CI, guards and the hosted lock tests stay on GitHub's runners inside the free plan's monthly minutes.
- **`.github/agent-runner/` (founder-owned):** one throwaway container per job under rootless Docker (`actions/runner`
  2.337.0 pinned by sha256, ephemeral, `--disableupdate`; base image by digest; non-root `runner` user; `--cap-drop ALL`
  plus only the lock's network/sudo capabilities; Docker's default seccomp profile plus the user-namespace calls bubblewrap
  needs, generated by `make-seccomp.py` from the vendored profile (Apache-2.0, `NOTICE.md`); 4 GB / `nproc÷lanes` CPUs /
  4096 pids per container). `agent-runner.sh` on the PC: `setup` (rootless Docker and `gh` checks, firewall kernel modules,
  user namespaces for bubblewrap, config, user service), `build`, `check` (the lock in a container, no registration),
  `start`/`stop`/`status`, `lane <n>` (registration token on stdin -> one job -> again).
- **Network lock container mode** (`AGENT_LOCK_CONTAINER=1`): same allow-list, proxy, firewall, sudo removal and self-test;
  no AppArmor/sysctl (host settings), `resolv.conf` rewritten in place, the self-test requires a non-root job with `CapEff`
  0. New messages in `docs/runbooks/agent-network-lock.md`. Tested in `scripts/check-egress-lock.test.sh` (container cases)
  and by the new `lock-container` job in `egress-lock-test.yml` (the PR's lock on a real lane, no secrets).
- **Workflow checker:** jobs with a Claude step must use exactly `[self-hosted, agents]`; any other job must use
  `ubuntu-latest` or that list; no expressions in `runs-on`.
- **New guard `scripts/check-agent-runner.sh`** (guards on the PR's files as data, and CI): pins, non-root, capabilities,
  seccomp regenerated, tokens only on stdin, notice. Tests in `scripts/check-agent-runner.test.sh` (guard on broken copies;
  host script with stubbed docker/gh/systemctl/sudo).
- Runbook `docs/runbooks/agent-runner.md` (setup commands, upgrades, failures, the guard's messages, limits, the founder
  decision on the host's user-namespace switch); `SETUP.md` step 5 and costs; `docs/architecture.md`.
